# 通用降噪 vs 注册条件化 TSE：声纹特征四路对比

**日期：** 2026-10-17  
**项目：** 中国移动鸿鹄实习 · 跨设备噪声鲁棒声纹识别  
**目的：** 解释“为什么用原通用降噪方法增强后，声纹识别准确率反而下降”，并与现有注册条件化 TSE 方法做四路对比（clean / noisy / 原方法 / TSE）。

> 本分析严格使用当年那两次实验的原始产物：原始 wav、原始 ERes2Net embedding、原始 `result.metrics` 和原始 trial 分数。没有重训模型，也没有重跑降噪推理。

## 2. 全局结果

| 条件 | EER (%) | minDCF | target 均值 | nontarget 均值 | target−nontarget | d′ | cos 到 clean embedding |
|---|---:|---:|---:|---:|---:|---:|---:|
| Clean | 5.2928 | — | 0.4903 | 0.0597 | 0.4307 | 3.322 | 1.000 |
| Noisy 0 dB | 8.3912 | 0.6283 | 0.4220 | 0.0513 | 0.3708 | 2.752 | 0.820 |
| **FullSubNet+（原）** | **10.1132** | **0.7058** | **0.3905** | 0.0583 | **0.3322** | **2.544** | **0.714** |
| **TSE（现有）** | **4.8921** | **0.5145** | **0.4713** | 0.0539 | **0.4175** | **3.416** | 0.816 |

**直接结论：**

1. 原方法把 EER 从 8.39% 推到 **10.11%**，比不处理还差 1.72pp。
2. 原方法把 target 分数均值从 0.422 降到 **0.391**，把 target−nontarget gap 从 0.371 压到 **0.332**，d′ 从 2.75 降到 **2.54**。
3. 原方法把同一句的 embedding 推得离 clean 更远：cos 从 Noisy 的 **0.820** 降到 **0.714**；TSE 为 0.816。
4. TSE 的 target 分数 0.471、gap 0.417、d′ 3.416，EER 4.89%，优于 clean 的 5.29%。

## 4. 频谱层面：原方法到底做了什么

在 **120 条随机测试语音** 上统计（不是手挑样本）：

| 条件 | low 20–500 Hz | mid 0.5–2 kHz | high 2–7.6 kHz | 谱倾斜 | RMS 增益 | SI-SDR | shape RMSE | 平均 dB 差 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| Clean | 0.692 | 0.281 | 0.027 | −25.1 | −33.5 dBFS | — | — | — |
| Noisy 0 dB | 0.549 | 0.285 | 0.166 | −18.9 | +2.6 dB | −0.52 dB | 3.97 dB | +1.35 dB |
| **FullSubNet+（原）** | 0.682 | 0.300 | **0.018** | **−28.2** | **+19.7 dB** | **+8.07 dB** | **7.19 dB** | **+15.42 dB** |
| **TSE（现有）** | 0.600 | 0.364 | 0.036 | −22.2 | −4.4 dB | +7.09 dB | 3.89 dB | −4.29 dB |

- `low/mid/high` 是该频带能量占比；`谱倾斜`越负表示高频衰减越强；`shape RMSE` 是去掉整体偏移后的 log-mel 谱形均方根误差，越小越接近 clean。
- 原方法把 high 频带能量占比从 Noisy 的 **0.166** 压到 **0.018**（比 clean 的 0.027 还低），谱倾斜从 −18.9 变到 **−28.2**：**过度压制高频**。
- 原方法 RMS 增益 **+19.7 dB**、平均 log-mel 比 clean 高 **15.4 dB**（峰值归一化 + 低频偏置），shape RMSE **7.19 dB**，约为 TSE（3.89 dB）的 **1.85 倍**。
- TSE 的 high 占比 0.036、谱倾斜 −22.2、shape RMSE 3.89，整体更接近 clean/Noisy；它没有把高频语音细节一起压掉。

## 5. 信号级 / 感知级指标（120 条随机样本）

### 5.1 绝对值（clean 作为参考）

| 条件 | SI-SDR (dB) | VAD 分段 SNR (dB) | PESQ-WB | STOI |
|---|---:|---:|---:|---:|
| **Clean（参考）** | —（参考） | —（参考） | **4.644** | **1.000** |
| Noisy 0 dB | −0.52 | 5.03 | 1.305 | 0.654 |
| FullSubNet+（原） | 8.07 | 20.69 | 1.889 | 0.750 |
| TSE（现有） | 7.09 | 13.43 | 1.958 | 0.739 |

PESQ/STOI 是参考型指标：clean-vs-clean 是上限（PESQ 4.644、STOI 1.000）。SI-SDR/SNR 的 clean 是参考信号本身，没有有限值，所以标“参考”。

**为什么 PESQ 离 clean 这么远？** PESQ 是全参考指标，4.644 只对“和 clean 完全相同”的信号成立，而且它不是百分比。用同一批实际噪声残差扫输入 SNR（20 条测试语音）：

| 输入 SNR | 20 dB | 10 dB | 5 dB | 0 dB | −5 dB | Clean |
|---|---:|---:|---:|---:|---:|---:|
| PESQ-WB | 3.18 | 2.15 | 1.69 | 1.32 | 1.19 | 4.644 |
| STOI | 0.925 | 0.832 | 0.762 | 0.660 | 0.593 | 1.000 |

实际 noisy 的平均输入 SNR = **0.33 dB**，PESQ **1.333**，和 0 dB 扫描点 1.323 几乎逐位吻合——说明计算没问题，0 dB 下 PESQ ~1.3 就是这个量级。增强后 ~1.9 已经是从 0 dB 往 5–7 dB 质量走了一大步，但不能指望达到 4.6。图：`figs/pesq_vs_snr.png`。

### 5.2 相对 Noisy 的提升

| 条件 | SI-SDRi (dB) | SNR 提升 (dB) | ΔPESQ | ΔSTOI |
|---|---:|---:|---:|---:|
| FullSubNet+（原） | +8.59 | +15.67 | +0.584 | +0.096 |
| TSE（现有） | +7.62 | +8.40 | +0.653 | +0.085 |

- 提升都是相对 Noisy 的配对差值；VAD 分段 SNR 使用 clean 能量定义噪声帧/语音帧，取同一信号内语音帧功率与噪声帧功率之比；PESQ-WB 用官方 `pesq` 0.0.4，STOI 用 `pystoi` 0.4.1，均为 16 kHz。
- **原方法在 SI-SDR / SNR / STOI 上更好**（SI-SDRi +8.59 vs +7.62 dB；SNR +15.67 vs +8.40 dB；STOI 0.750 vs 0.739），PESQ 略低于 TSE（1.889 vs 1.958）。
- 但 EER 是 **10.11% vs 4.89%**：标准增强指标更好的一项，声纹反而更差。
- 逐句改善比例：原方法 PESQ 85.8%、STOI 87.5%、SI-SDR 95.8%、SNR 99.2%；TSE 分别为 99.2%、95.0%、96.7%、95.0%。TSE 在 PESQ 上更稳定，但均值上原方法在 SI-SDR/SNR/STOI 更高。
- 图：`figs/intrusive_metrics.png`。

**结论：** 标准增强指标（尤其 SI-SDR/SNR/STOI）不能代表声纹身份保持；TSE 不是靠“更干净”赢，而是靠“更像注册的人”。

### 5.3 三个 SNR 的区别（重要口径）

| 指标 | 0 dB 数据 | −5 dB 数据 | 含义 |
|---|---:|---:|---|
| 原始设定 SNR | 0 dB | −5 dB | 生成数据时设定的输入混合 SNR |
| 实测全局 SNR | 0.16 dB | −4.53 dB | clean 与噪声的总能量比，用于验证设定 |
| 带噪 SI-SDR | −0.52 dB | −5.52 dB | 全参考、尺度不变；对纯加噪 ≈ 输入 SNR |
| 带噪 VAD-SNR | 5.03 dB | 3.06 dB | 分段语音帧/噪声帧功率比，不是全局 SNR |

- 你一开始的 0 / −5 dB 是**输入混合 SNR**；实测全局 SNR 为 0.16 / −4.53 dB，和设定基本一致（差 0.2–0.5 dB 来自对齐、端点与能量统计）。
- **SI-SDR** 是 `ŝ = αs + e` 的最优缩放分解，`10log10(||αs||²/||e||²)`；它对整体增益不敏感，残差里包含残余噪声 + 语音失真 + 伪影。对纯加噪数据，SI-SDR ≈ 输入 SNR（这里 −0.52 / −5.52 dB，差 <1 dB）；对增强后，SI-SDRi 是相对带噪的提升。
- **VAD-SNR** 是分段指标：用 clean 能量取 top 60% 语音帧、bottom 20% 噪声帧，算同一信号内“语音帧功率 / 噪声帧功率”。它不是全局 SNR，所以 0 dB 数据算出 5.03 dB 不矛盾；−5 dB 数据也只有 3.06 dB，因为低 SNR 下 VAD 帧会混入更多语音泄漏，比值被压缩。**不要把 VAD-SNR 的绝对值直接和 0 / −5 dB 比较，也不要把 +15.67 dB 的 VAD-SNRi 加到 0 dB 上当作输出 SNR。**
- 如果论文里要报“输出 SNR”，建议明确写“VAD-segmental SNR”并给出定义；或者直接用 SI-SDRi（全参考、尺度不变）作为主指标。

### 5.4 降噪后数据的全局 SNR（补充）

按“输出缩放到与带噪输入同整体 RMS”的口径（120 条测试句）：

| 数据 | Noisy | FullSubNet+ | Δ vs Noisy | TSE | Δ vs Noisy |
|---|---:|---:|---:|---:|---:|
| 0 dB | 0.16 | 3.96 | **+3.80** | 3.48 | **+3.32** |
| −5 dB | −4.53 | −1.37 | **+3.16** | −1.96 | **+2.57** |

- 未做电平匹配的 raw 全局 SNR 对原方法是 **−18.1 dB**（峰值归一化到 0.8 的增益差造成），不能直接比较；匹配后为 3.96 dB。TSE raw 为 5.82 dB。

## 6. 为什么原方法会把声纹弄坏

### 6.1 波形更干净 ≠ 声纹更准

120 条随机样本上：

- 原方法 SI-SDR **+8.07 dB**（SI-SDRi **+8.59**）、VAD 分段 SNR **20.69 dB**（提升 **+15.67**）、STOI **0.750**（Δ **+0.096**），三项都高于 TSE（+7.09 / +7.62、13.43 / +8.40、0.739 / +0.085）；PESQ 略低（1.889 vs 1.958）。
- 但 EER：原方法 **10.11%**，TSE **4.89%** → 信号级/可懂度指标与声纹指标方向相反。

这说明 FullSubNet+ 优化的 cIRM/信号重建目标，与“保留说话人身份”不是同一个目标。

### 6.2 原方法把 ERes2Net embedding 推离说话人流形

- 同一句 clean vs 各条件 embedding 余弦：Noisy **0.820**，原方法 **0.714**，TSE **0.816**。
- 原方法甚至比“完全不处理”还远，说明它引入的谱形改变不是简单的“去噪”，而是把 embedding 推到了另一个方向。
- 频谱形状畸变（shape RMSE）与 embedding 漂移的相关系数为 **−0.54**（360 个“语句×条件”点）；SI-SDR 与漂移的相关系数只有 **+0.13**。  
  → 声纹受损主要跟**谱形状畸变**相关，而不是残余噪声或波形保真度。

### 6.3 根因：无注册条件的通用降噪，目标函数与测试域都错位

1. **没有“保留谁”的信息**：FullSubNet+ 不知道注册说话人是谁，会把所有语音/噪声一起处理；在跨设备中文语音 + 强低频噪声上，它容易把目标语音的高频细节也当成噪声压掉。
2. **优化目标不是身份**：它训练的是 cIRM/信号重建，输出更像 clean 不等于 embedding 更像这个人。高频共振峰、辅音细节、精细谱包络这些对声纹关键的线索，恰好容易被通用降噪抹平。
3. **推理侧峰值归一化 + 低频偏置**：`0.8 * enhanced / max(abs(enhanced))` 让输出响度远高于 clean，且这批数据上低频能量占主导；FBank 的逐句均值归一化只能去掉整体增益，去不掉谱倾斜和伪影。
4. **跨域失配**：模型训练分布是 DNS 类数据，测试是 3D-Speaker 跨设备中文语音；模型在未见域上的 mask 估计不稳定，产生“降噪了但谱形变了”的结果。
5. **标准增强指标 ≠ 声纹指标**：SI-SDR/SNR/PESQ/STOI 衡量的是信号保真或可懂度；原方法在 SI-SDR/SNR/STOI 上更好，却把 embedding 推得更远。声纹系统需要的是身份判别性，不是波形相似度。

### 6.4 TSE 为什么能反过来改善

- TSE 用注册语音的声纹 embedding 经 **FiLM** 注入 FullSubNet+，只提取注册说话人；训练中还有 **说话人保持损失**（增强前后 embedding 余弦对齐）和 **难负原型抑制损失**。
- 它优化的不是“像 clean”，而是“增强后仍像注册的这个人”。因此：
  - 频谱形状更接近目标语音（shape RMSE 3.89 vs 原方法 7.19）；
  - embedding 留在说话人流形上（target 0.471、gap 0.417、d′ 3.416）；
  - EER 4.89%，甚至低于 clean 的 5.29%（注册条件化 + 通道归一化的效果）。
- 一个有意思的细节：TSE 的 cos 到 clean 只有 0.816，和 Noisy 的 0.820 差不多；但它的 **cos 到注册语音** 更高（0.471 vs 0.422）。它不是简单复刻 clean，而是把测试语音往“注册的这个人”方向拉——这正是注册条件化的作用。

## 7. 口径与局限

- 本页所有 TSE 数字都是 **oracle 口径**：用测试句真实说话人的注册语音做增强条件，对应交付主表。  
  **claim 口径**（冒认句用“声称者”的注册条件）存在条件信息泄漏，EER 会反弹（报告 §5 已单列），不能把 4.89% 直接外推到真实部署。
- 5 条逐句样本用于展示“原方法怎么坏、TSE 怎么修”，结论的统计支撑来自 8507 条测试语句 / 1,378,206 条 trial，以及 120 条随机样本的频谱统计和 SI-SDR/SNR/PESQ/STOI 统计。
- PESQ/STOI 的绝对值偏低是跨设备 clean 参考 + 0 dB 测试条件造成的；不同实现/版本会有小幅差异，本文统一用官方 `pesq` 0.0.4 和 `pystoi` 0.4.1，重点看相对提升和条件间对比。
- 原方法的“低频偏置/高频过度压制”是这批跨设备测试数据上的实测行为；换数据域后具体数值会变，但“无注册条件 + 信号重建目标 ≠ 声纹目标”这一机理不变。
