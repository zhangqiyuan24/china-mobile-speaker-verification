本报告是原技术报告的补充分析，不重复原报告已经给出的任务背景、数据协议、TSE 网络结构与主 EER 结果。它只回答三个问题：

  1. 为什么原通用 FullSubNet+ 降噪后，声纹 EER 反而变差？
  2. 原方法与注册条件化 TSE 在 embedding、时频、信号/感知指标上到底差在哪里？

关键数字：EER 8.391 → 10.113 → 4.892；target 0.422 → 0.391 → 0.471；同句 embedding 漂移 0.820 → 0.714 → 0.816（Noisy → 原方法 → TSE，0 dB）。完整四路对比表见 4.1。

1.2 结论摘要

原 FullSubNet+ 是一个无注册条件的通用降噪器：它把带噪语音往“clean 波形”方向重建，但不负责“保留谁”。在这批跨设备中文语音上，它确实让波形更接近 clean（SI-SDRi +8.59 dB、STOI +0.096、PESQ +0.584），却把 ERes2Net 的说话人 embedding 推离了 clean 的说话人流形（同句余弦 0.820 → 0.714），导致 target 分数下降（0.422 → 0.391）、target−nontarget gap 收窄（0.371 → 0.332）、EER 从 8.391% 升到 10.113%。

注册条件化 TSE 的波形指标并不全面占优（SI-SDRi +7.62 dB、STOI 0.739，均略低于原方法），但它的 embedding 留在说话人流形附近（余弦 0.816），target 分数升到 0.471，EER 降到 4.892%。这说明：“降噪指标更好”不等于“声纹前端更好”；声纹验证需要的是身份保持，不是波形保真。

本报告最想让你记住的三个数字： 0.714（原方法 embedding 到 clean 的余弦，比 Noisy 的 0.820 还低）；10.113%（原方法 EER，比不处理还差）；4.892%（TSE EER）。它们分别对应“embedding 被推远”“验证变差”“身份条件化修复”三步。

3　新增评测指标与公式

EER、minDCF、FAR/FRR、trial 协议在原报告中已有完整定义与主结果，本文不重复。下面只列本报告新增或重点使用的指标：它们回答的是“增强后的语音在信号、感知、身份三个层面发生了什么”，而不是重新评价主系统。

3.1 Embedding 余弦、target 分数与 embedding 漂移

ERes2Net 把每条语音映射成 512 维单位向量。两个 embedding 的余弦相似度衡量“像不像同一个人”：

s(𝐚,𝐛)=⟨𝐚,𝐛⟩‖𝐚‖2‖𝐛‖2
(1)

对测试语音 t，用同说话人的 clean 注册语音得到注册 embedding 均值 eenr，target 分数为 st = cos(et, eenr)。同时把同句在 clean 与增强条件下的 embedding 做余弦，得到 embedding 漂移 dt：

st=cos(𝐞t,𝐞enr),dt=cos(𝐞tcond,𝐞tclean)
(2)

target 分数越高，说明越像注册者；漂移越接近 1，说明增强后 ERes2Net 仍把这句话放在原来的说话人位置。两者一个看“注册相似度”，一个看“增强把 embedding 挪了多远”，本报告同时报告。

3.2 SI-SDR 与 SI-SDRi

SI-SDR 把估计信号 ŝ 分解为“clean 的最优缩放副本 + 残差”：

𝐬^=α𝐬+𝐞,α=⟨𝐬^,𝐬⟩⟨𝐬,𝐬⟩
(3)
SI-SDR=10log10‖α𝐬‖22‖𝐬^−α𝐬‖22
(4)
SI-SDRi=SI-SDR(𝐬^)−SI-SDR(𝐱)
(5)

SI-SDR 是尺度不变的：整体音量不影响数值；残差 e 包含残余噪声、语音失真、增强伪影与对齐误差。对纯加噪输入，SI-SDR 近似输入 SNR；对增强后，它衡量“离 clean 有多远”。SI-SDRi 是相对带噪输入的提升，单位 dB，越高越好。

3.3 全局 SNR：与输入同电平的残差比

输入混合 SNR 是 clean 与噪声的能量比：

SNRin=10log10‖𝐬‖22‖𝐱−𝐬‖22
(6)

对增强后的信号，直接算“clean 能量 / 残差能量”会遇到增益陷阱：原 FullSubNet+ 把输出峰值归一化到 0.8，整体增益比 clean 高约 20 dB；不匹配电平会得到无意义的负 SNR。因此本报告先把增强输出缩放到与带噪输入相同的整体 RMS，再算：

β=‖𝐱‖2‖𝐬^‖2,SNRout=10log10‖𝐬‖22‖β𝐬^−𝐬‖22
(7)
ΔSNR=SNRout−SNRin
(8)

其中 β = ‖x‖2 / ‖ŝ‖2。这样带噪基线就是它原本的输入 SNR（0 dB 数据实测 0.16 dB，−5 dB 实测 −4.53 dB），增强后的数值与它同电平可比。报告中的“全局 SNR 提升”均指这个 ΔSNR。

三个 SNR 不要混：你最初设置的 0 / −5 dB 是输入混合 SNR；SI-SDR 是尺度不变的全参考失真比；本文的 VAD-SNR 是分段语音帧/噪声帧功率比。同一批 noisy 数据上实测：0 dB 数据的全局 SNR 0.16 dB、SI-SDR −0.52 dB、VAD-SNR 5.03 dB；−5 dB 数据分别为 −4.53 / −5.52 / 3.06 dB。VAD-SNR 的绝对值本来就不等于输入 SNR，不能把“VAD-SNRi +15.67 dB”加到 0 dB 上当作输出 SNR。

3.4 VAD 分段 SNR

先用帧能量：

e(n)=1W∑k=0W−1s2(n+k)
(9)

用 clean 的帧能量选出语音帧 S（能量最高 60%）与噪声帧 N（最低 20%），再在同一信号内算语音帧平均功率与噪声帧平均功率之比：

SNRVAD=10log101|S|∑n∈Ss^2(n)1|N|∑n∈Ns^2(n)
(10)

它衡量“语音段相对噪声段高多少”，对噪声底抑制敏感，但不惩罚语音失真；因此通常比全局 SNR 高很多。正确用法是在同一定义下比较不同前端，例如原方法 20.69 dB、TSE 13.43 dB，而不是拿它和 0 / −5 dB 直接换算。

3.5 PESQ-WB

PESQ 是 ITU-T P.862 的全参考感知质量指标，16 kHz 版本为 P.862.2（PESQ-WB）。流程是：电平对齐 → IRS 滤波 → 时间对齐 → Bark 域感知变换 → 对称/非对称扰动 → 聚合 → MOS-LQO 映射。可用下面的框架理解：

Dsym(f,t)=|LX(f,t)−LY(f,t)|
(11)
Dasym(f,t)=max(Dsym(f,t)−m(f,t),0)
(12)
PESQ=fMOS(𝒜[Dsym,Dasym])
(13)

LX、LY 是 Bark 频带响度；Dsym 是对称扰动，Dasym 是对“参考有、待测没有”的成分加罚；𝒜 是时间/频带聚合，fMOS 是标准映射。精确常数由 ITU-T P.862 规定，没有简单闭式公式。

PESQ 范围约 −0.5–4.5（本报告用官方 pesq 0.0.4，clean-vs-clean 为 4.644），而且非线性：1.3 → 1.9 不是“28% → 41%”。0 dB 下 PESQ 1.3–2.0 是正常量级；本数据 20 dB 也只有 3.18。请看同条件下的相对提升，不要拿它对 clean 的 4.644 做百分比。

3.6 STOI

STOI 在 1/3 倍频带上比较短时包络的归一化相关：

dj,m=∑n(xj,m(n)−x¯j,m)(yj,m(n)−y¯j,m)∑n(xj,m(n)−x¯j,m)2∑n(yj,m(n)−y¯j,m)2
(14)
STOI=1JM∑j=1J∑m=1Mdj,m
(15)

范围 0–1，越高越好；比 PESQ 更“线性”、更少饱和，但同样衡量可懂度/包络保真，不是说话人身份。标准实现还会对相关值做裁剪/归一化，具体以原文和 pystoi 为准。

3.7 d′ 与 shape RMSE

d′ 衡量 target 与 nontarget 两个分数分布的分离度：

d′=μtarget−μnontarget12(σtarget2+σnontarget2)
(16)

d′ 越大，两个分布越分开。shape RMSE 用 80 维 log-mel 谱形衡量增强后“精细谱包络”离 clean 多远：

XdB(m,t)=10log10(∑k|X(k,t)|2Hm(k))
(17)
RMSEshape=1|Ω|∑(m,t)∈Ω[(XdBcond(m,t)−XdBclean(m,t))−Δ―]2
(18)

其中 Ω 是 clean 的活跃时频点，Δ̄ 是整体偏移；去掉偏移后只看谱形。shape RMSE 越低，谱形越接近 clean；它和 embedding 漂移有较强相关性（本报告 360 个“语句×条件”点 r = −0.54），是解释“为什么声纹会坏”的中间层证据。

4.8 结果小结

  • 验证：原方法 EER 10.113%、target 0.391、gap 0.332、d′ 2.544、drift 0.714；TSE 4.892%、0.471、0.418、3.416、0.816。
  • 信号/感知：原方法 SI-SDRi +8.59 dB、VAD-SNRi +15.67 dB、PESQ 1.889、STOI 0.750；TSE +7.62、+8.40、1.958、0.739。原方法三项更好，PESQ 略低。
  • 全局 SNR（输入同电平）：0 dB 原方法 +3.80 dB、TSE +3.32 dB；−5 dB +3.16 / +2.57 dB。
  • 频谱：原方法 high 占比 0.018（clean 0.027）、谱倾斜 −28.2、shape RMSE 7.19；TSE 0.036、−22.2、3.89。
  • 一句话：原方法是一个更好的“降噪器”，但 TSE 是一个更好的“声纹前端”。

5　失效机理：为什么原方法会坏

原报告已经给出了 TSE 的网络结构、FiLM 注入与四项损失；本节不重复模型介绍，只解释“为什么通用降噪会让声纹变差”，以及 TSE 为什么能避开这个问题。

5.1 原 FullSubNet+ 的失效链

环节观察解释
① 目标函数FullSubNet+ 优化 cIRM/信号重建，训练分布是 DNS 类通用数据；没有注册条件。它优化“增强信号像 clean”，不优化“增强后仍像同一个人”；也不知道要保留谁。
② 频谱行为high 频带占比 0.166 → 0.018；谱倾斜 −18.9 → −28.2；shape RMSE 7.19 dB；输出峰值归一化到 0.8。高频目标语音细节被过度压制，低频/宽带能量被抬升；增益和伪影进一步改变谱包络。
③ embedding同句 cos 到 clean：0.820 → 0.714；target 0.422 → 0.391；gap 0.371 → 0.332；d′ 2.752 → 2.544。ERes2Net 依赖的精细谱结构被改写，embedding 离开说话人流形；注册相似度和类间可分性同时下降。
④ 系统结果EER 8.391% → 10.113%，比不处理还差 1.72pp。波形/感知指标可以更好，但验证指标由 embedding 决定，所以“降噪更好”没有转化为“声纹更好”。

这条链的关键是 ②→③：如果只看波形，原方法确实更接近 clean（SI-SDR 8.07 dB、VAD-SNR 20.69 dB、STOI 0.750）；但 ERes2Net 不直接“看波形”，它看的是 FBank 的精细谱包络。谱形被改写后，embedding 漂移比“完全不处理”还大。这也是为什么“降噪指标”和“声纹指标”会背离。

一句话：原方法不是“降噪把语音压没了”，而是“降噪把说话人 embedding 推到了错误方向”。它优化的是信号重建，不是身份保持；高频细节的过度压制和低频/增益伪影是中间机制，embedding 漂移和 target 下降是直接原因，EER 变差是最终结果。

5.2 TSE 为什么能保住身份

  • 注册条件化：注册 embedding 经 FiLM 注入 FullSubNet+，增强时模型知道“保留谁”，可以把非目标语音/噪声压掉，而不是把所有语音能量都当目标。
  • 说话人保持损失：训练时约束增强前后 embedding 的余弦，使增强后的语音仍然落在注册者的 embedding 附近；这直接对齐了声纹目标。
  • 难负原型抑制：对最难的干扰说话人原型做间隔惩罚，增大 target 与 hard negative 的分离度；d′ 从 2.752 提到 3.416。
  • 不是复刻 clean：TSE 的 cos 到 clean 只有 0.816（与 Noisy 0.820 接近），但 target 是 0.471（Noisy 0.422）。它把语音往“注册的这个人”方向拉，而不是简单复制 clean 录音。

TSE 的 FiLM 结构、四项损失、消融链与训练细节见原报告第 5 章；本报告只保留“它为什么能改善声纹”这条因果链。

5.3 边界与引用注意

  • Oracle 口径：本报告 TSE 的 4.892% 是 oracle 口径（用测试句真实说话人的注册语音做条件），对应交付主表；claim 口径（冒认句用声称者的注册条件）存在条件信息泄漏，EER 会反弹，不能把 4.892% 直接外推到真实部署。完整分析见原报告附录 C（部署口径与局限性）。
  • 条件：主分析是 0 dB；−5 dB 只补充了 EER/全局 SNR/SI-SDR。PESQ/STOI 的绝对值受跨设备 clean 参考和 0 dB 条件影响，应看相对提升。
  • 样本量：信号/感知/频谱指标在 120 条随机测试句上统计；5 条展示样本用于可视化，不是统计结论的全部依据；逐句 target/漂移覆盖 8,507 条测试句。
  • 对比：原方法是通用 FullSubNet+，TSE 是在其基础上加入注册条件与身份损失训练得到的；这是“两条工程路线”的对比，不是“同预算、同目标”的消融。结论是“在本项目的数据和协议上，身份条件化更适合声纹前端”，不是“所有通用降噪都一定有害”。
  • 指标：SI-SDR/SNR/PESQ/STOI 是信号/感知指标，不是说话人身份指标；全局 SNR 与 VAD-SNR 是不同定义，不能互换或相加。

7　面试速答与口径建议

7.1 三句话版本

① 现象：通用 FullSubNet+ 把 0 dB EER 从 8.39% 推到 10.11%，比不处理还差；注册条件化 TSE 把它降到 4.89%。
② 证据：原方法的 SI-SDR/SNR/STOI 其实更好，但它把 ERes2Net embedding 到 clean 的余弦从 0.820 拉到 0.714，target 从 0.422 降到 0.391，高频能量占比从 0.166 压到 0.018。
③ 机理：通用降噪优化“像 clean”，不优化“像这个人”；TSE 用注册 embedding 经 FiLM 注入 + 说话人保持损失 + 难负原型抑制，优化“增强后仍像注册者”，所以信号指标不占优，声纹指标全面更好。

7.2 常见追问

问题建议回答（带数字/口径）
为什么通用降噪后 EER 反而变差？它优化 cIRM/信号重建，不是说话人身份。0 dB 下 SI-SDRi +8.59 dB、STOI +0.096，确实更干净；但同句 embedding 到 clean 的余弦只有 0.714（Noisy 0.820），target 0.391（0.422），gap 0.332（0.371），d′ 2.544（2.752）。波形更接近 clean，embedding 却被推离了说话人流形。
怎么证明是声纹特征被破坏，而不是噪声没降干净？① 它的 SI-SDR/VAD-SNR/STOI 都比 Noisy 和 TSE 高（或部分更高），不是“没降噪”；② 谱形畸变（shape RMSE 7.19 dB）与 embedding 漂移的相关系数是 −0.54（360 个语句×条件点），而 SI-SDR 与漂移只有 +0.13。坏的中间量是谱形/embedding，不是残余噪声。
TSE 为什么能改善？注册 embedding 经 FiLM 注入，让增强知道保留谁；说话人保持损失约束增强前后 embedding 余弦；难负原型抑制增大 target 与 hard negative 的间隔。结果 target 0.471、gap 0.418、d′ 3.416、EER 4.89%，都优于原方法和 Noisy。它不是复刻 clean：cos 到 clean 0.816 与 Noisy 0.820 接近，但 cos 到注册语音更高。
SNR 提升了多少？先说口径。① 全局 SNR（输出缩放到与输入同 RMS）：0 dB 下原方法 0.16→3.96（+3.80 dB），TSE 0.16→3.48（+3.32 dB）；−5 dB 下 −4.53→−1.37（+3.16）/ −1.96（+2.57）。② SI-SDRi（尺度不变）：+8.59 / +7.62 dB（0 dB），−5 dB +11.47 / +9.59 dB。③ VAD-SNRi（分段噪声底）：+15.67 / +8.40 dB（0 dB）。三个不是同一个量，不能相加或互换。
PESQ 为什么只有 1.9？测试是 0 dB，PESQ 是全参考、非线性指标，4.644 只对 clean-vs-clean 成立。用实际噪声扫 SNR：20 dB→3.18、10 dB→2.15、5 dB→1.69、0 dB→1.32、−5 dB→1.19；实际 noisy PESQ 1.333，与 0 dB 点吻合。1.9 已经是 0 dB 下的合理提升，不能和 clean 的 4.6 做百分比。
claim 口径怎么样？本报告和交付主表是 oracle 口径（真实说话人注册），4.89% 是验收上限；claim 口径（冒认句用声称者注册条件）存在条件信息泄漏，EER 会反弹，不能直接外推到部署。完整分析见原报告附录 C（部署口径与局限性）。

7.3 容易踩的坑

建议的报法：主结果（EER/minDCF/claim）引用原报告；本补充报告报 SI-SDRi + PESQ/STOI + 全局 SNR Δ，并明确每个 SNR 的定义。不要把 VAD-SNRi 当输出 SNR，也不要在 0 dB 下拿 PESQ 绝对值和 clean 的 4.644 比。
  • 只说“降噪把声纹抹掉了”：太笼统。要加证据：embedding 漂移 0.714、target 0.391、高频占比 0.018、shape RMSE 7.19。
  • 把 VAD-SNR 的提升直接说成“输出 SNR”：+15.67 dB 是 VAD-SNRi，不是“0 dB → 15.67 dB”；全局 SNR 提升是 +3.80 dB（0 dB 数据，输入同电平口径）。
  • 拿 PESQ 1.9 和 clean 4.6 做百分比：PESQ 非线性，0 dB 下 1.3 是正常起点；要说“相对 Noisy 提升 +0.584 / +0.653”。
  • 把 oracle 的 4.89% 说成部署性能：claim 口径会反弹；主动说明边界。
  • 说“通用降噪一定有害”：更准确的说法是“在本项目数据/协议上，无条件通用降噪与声纹目标错位；身份条件化更合适”。
