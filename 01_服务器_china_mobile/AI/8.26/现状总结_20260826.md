## 3. 负提升 / 无效方法清单（官方口径或预声明判据）

| 方法 | 结果 | 结论 |
|---|---|---|
| AS-Norm 分数归一 | 8.21 验证为负增益 | clean cohort 与噪声测试分布不匹配，弃用 |
| WavLM zero-shot 融合成员 | 融合 grid 自动给 0 权重 | 无融合价值 |
| WavLM 微调（域适配） | 6ep 后 EER 15~27%，斜率外推不可用 | SSL 骨干在此数据量下不可用，降级 teacher |
| born-again 蒸馏（soup teacher） | kd≈0.03~0.06 温和正则 | 仅弱汤成员，无决定性增益 |
| SAM / 一致性正则（consist） | 弱成员 | 同上（"缺第二个 8% 以内异构强成员"） |
| 90k 数据扩充（两次：8.22、8.24 proto_90k） | proto_90k raw −1.0%/−4.8%，弱于 8.21；ep1 即最优后漂移 | **"更多数据"假设两次证伪** |
| channel_aug 信道增强 | 官方五条件全胜对照但仅 +0.07~0.26pp | 有效但非决定性（val bench 测不到信道收益，官方口径定夺正确） |
| GateNet 特征门控 | ep1 8.000 → ep2 8.250（bar 7.5） | 按预声明规则止损 |
| 嵌入级平均融合（4 模型全组合） | 最好 7.5875/9.5350 | 远弱于分数融合（同构空间旋转失配）——反向印证权重 soup 价值 |
| ECAPA 配方迁移（噪声档） | 0dB −0.5% / −5dB +5.9% | 配方在弱骨干上不迁移（clean 档 −14.7% 有效） |
| MoE-lite ep3 | avg01 7.500 ≥ 锚 7.375 | 止损（0dB 单档有收益） |

## 5. 关键方法论结论

1. **地板-缝隙分解**：噪声 EER = clean 地板 + 噪声缝隙。后端多条件训练把地板压到 5.08（基线 5.82）后**饱和**；剩余矛盾全在缝隙轴。
2. **TSE 是迄今最强单杠杆**：注册条件化提取直接攻缝隙轴，胜过通用降噪前端，且模型无关性双骨干实证。
3. **汤（权重平均）在同源成员上有效但已饱和**（7.475 ≈ 7.468 天花板）；缺第二个异构强成员是融合线瓶颈。
4. **数据扩充在 90k 规模已饱和**（两次独立证伪）。
5. **小 val 与官方协议背离**（ECAPA 漂移 6pp）——后续任何选型必须官方口径定夺，小 val 只做粗筛。
6. 单人说话噪声（babble 型）是最难档位，与 NCMoE 文献结论一致。
