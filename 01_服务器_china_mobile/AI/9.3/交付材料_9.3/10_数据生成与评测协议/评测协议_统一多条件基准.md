## 1. 数据来源

- 主验收集:**3D-Speaker 中文数据**(训练集 190 GB、579,003 条、9,900 说话人;官方测试集 240 人、18,782 条);VoxCeleb 仅用于骨干预训练。
- 说话人隔离:训练 / 代理验证(100 人,训练与测试均未见)/ 官方测试三方互不重叠,准备脚本运行时断言。
- 可复现性:训练与评测主链 seed=2026;数据侧的噪声/RIR 训测拆分脚本自带独立固定 SEED=42(split_noise_rir.py),两者均为确定性生成。

## 3. 八套测试语音 × 三档时长

每套条件均派生 1s / 3s / 5s 三档(验收档 = 3s;A+D 侧每格 16,401 条 3s 测试语音):

| # | 条件目录 | 构成 |
|---|---|---|
| 1 | clean | 官方测试语音干净版 |
| 2 | noise_0db | MUSAN free-sound 测试池加噪,SNR 0 dB |
| 3 | noise_m5db | 同噪声同位置,仅 SNR 改 -5 dB(两档严格配对) |
| 4 | reverb | 模拟 RIR 卷积(中房间,T60 中位 0.60 s) |
| 5 | overlap2_cn | 二人重叠·中文(干扰取自 B 池,记录 TIR) |
| 6 | overlap3_cn | 三人重叠·中文(B∪C 池,记录 TIR) |
| 7 | overlap2_en | 二人重叠·英文(干扰取自 E/F 池) |
| 8 | overlap3_en | 三人重叠·英文(已构建;分项主表未列入,见报告 §6.2) |

重叠条件逐条记录元数据(`overlap_metadata.csv`);`ori/` 保留派生前原始版本,`denoised/` 为增强输出落盘区。

## 6. 指标与判定

- **指标**:EER(官方打分脚本插值计算,自建复算与之逐位对账,偏差 >0.5pp 报警);minDCF(NIST 口径,p_tar=0.01、c_miss=c_fa=1);ROC/DET 曲线(2001 阈值点,DET 正态概率刻度,`AI/8.30/gen_roc_det.py`);固定工作点 FAR=5% 处 FRR、FRR=5% 处 FAR。
- **时长档**:1s / 3s / 5s;验收档 = 3s。
- **验收线**:相对未增强骨干降幅 ≥30%(主力后端对应 0dB/-5dB 达标线 5.874 / 7.739);挑战目标 EER ≤0.5% 未冲击。
- **官方原始协议**(校准用):3D-Speaker 自带 cross-device / cross-distance / cross-dialect 清单(`data/files/`,cross_device 180,000 条),三协议共 535,163 条 trial 用于管线校准,与上述统一基准相互独立。

## 7. 判定纪律

1. 阈值/选点只在验证侧确定(训练期 = 100 人代理验证集,含困难试验子集),官方测试集冻结、不得依据测试反馈调参;
2. 官方测试每个决策只跑一次,结果记档;
3. EER / minDCF 为无阈值指标;固定工作点为打分分布上的分位数扫描(描述性报告);
4. 原始打分文件、曲线 CSV、`result.metrics` 全部落盘(交付材料 06_指标),可复现。

## 8. 数据生成代码(本目录附原件)

以下 10 个脚本即生成全部协议数据的原始代码,原件位于服务器 `code/3D-speaker/3D-speaker/egs/3dspeaker/sv-ecapa/`(未改动,本目录为拷贝):

| 脚本 | 作用 |
|---|---|
| gen_all_test_data.sh | 一键总入口:先拆噪声/RIR 池,再生成全部测试条件 |
| gen_test_conditions.py | 12 种测试条件生成驱动(场景定义、随机种子与目录结构) |
| gen_clean_benchmark.py | clean 基准:能量 VAD 锚定截取 1s/3s/5s(不足时长按自然节奏重复补齐) |
| gen_clean_protocols.py | 评测协议构建:三档时长使用完全相同的 trial 配对,对齐官方 3D-Speaker 构法(enrollment.csv / trial.csv 即其产物) |
| gen_noise_benchmark.py | 单说话人噪声:每条语音随机取测试池噪声,0 dB 与 -5 dB 同噪声同位置仅 SNR 不同 |
| gen_reverb_benchmark.py | 混响:simulated_rirs/mediumroom 卷积(T60 ≈ 0.63 s 池,实测中位 0.60 s) |
| gen_overlap_benchmark.py | 多人重叠:A/D + B/C(中文)或 E/F(英文)干扰,记录 TIR 与 overlap_metadata.csv |
| split_noise_rir.py | 噪声/RIR 训练-测试物理隔离(SEED=42,输出 divide/ 四清单) |
| stat_rir_t60.py | RIR T60 统计(Schroeder 反向积分 + 线性回归,"T60 中位 0.60 s"出处) |
| stat_test_duration.py | 测试集采样率与时长分布核查 |

执行顺序:split_noise_rir.py → gen_test_conditions.py(内部调四个 *_benchmark.py)→ gen_clean_protocols.py;总入口为 gen_all_test_data.sh。
