# 中文声纹识别噪声鲁棒性方案评估：−30% 相对 EER 降幅的可达性分析（送审版）

> 目的：评估"speaker-aware 前端增强（跨句对比 loss 微调 FullSubNet+，冻结声纹模型）"能否达成课题验收指标，并给出修订后的方案建议。
> 请求审核者重点检验：第 3 节的"clean 地板"论证是否成立、第 6 节的概率估计是否合理、第 4 节文献引用是否准确。
> 标注约定：【事实】= 有实验数据支撑；【推理】= 逻辑推演；【文献】= 公开发表工作（细节请审核者核验）；【主观概率】= 作者经验估计，可校准。

---

## 1. 任务协议与关键数字【事实】

- 数据：3D-Speaker 中文集。开集声纹验证，训练/测试说话人不重叠，测试噪声（freesound 划分）与训练噪声严格隔离（train 675 条 / test 168 条，零重叠）。
- 评测：clean enrollment（3 s）vs 测试语音（3 s），trials_cross_device（约 138 万条，含跨设备），embedding 模型为冻结的 ERes2Net-large（3D-Speaker 预训练，modelscope `speech_eres2net_large_sv_zh-cn_3dspeaker_16k`），cosine 打分，报告 EER / minDCF(p=0.01)。
- 验收指标（子课题一）：-5 dB 和 0 dB 单说话人噪声两档，相对主验收基线 EER 降幅均 ≥30%。挑战目标 EER≤0.5%。

| 条件 | 基线 EER（eres2net, 3s） | 基线 minDCF | −30% 目标 EER | 当前最好结果 |
|---|---|---|---|---|
| clean | 5.82（另一轮测得 5.29） | 0.518 | — | — |
| 0 dB | 8.3911 | 0.6283 | **≤5.874** | 7.7902（−7.2%） |
| −5 dB | 11.0557 | 0.6865 | **≤7.739** | 9.9186（−10.3%） |

当前最好结果来源：FullSubNet+（预训练）+ speaker-preserving 微调，loss = L_se(cIRM MSE) + 0.5·L_spk(同句 clean/enhanced embedding 余弦一致)，冻结 ERes2Net；30k 条训练语音（全量 643k 均匀抽取）× 10 epochs。

## 2. 直接回答核心问题：前端方案能不能保证 −30%？

**不能保证。且经定量推演，"仅前端（冻结声纹模型）"路线在 0 dB 档几乎不可能达标**，论证见第 3 节。作者此前建议该路线时的表述（"通往 30% 的唯一路径"）过于乐观，本文予以修正。

## 3. 关键定量论证：clean 地板【推理，请重点审核】

评测协议为 clean enrollment vs enhanced test。若增强输出恰为 clean 波形（oracle 增强），则测试 embedding = clean 测试集 embedding，EER 收敛到 clean-clean 跨设备水平，即 **≈5.3~5.8%**（同一冻结模型实测）。任何非完美增强都会引入残差噪声或处理伪影，EER 只会高于此值。

- **0 dB 档：目标 ≤5.874，地板 ≈5.3~5.8。达标余量 ≈ 0~0.5 个 EER 点。** 即：仅前端路线在 0 dB 达标≈要求接近 oracle 的增强质量。对 3 s、跨设备、未见噪声，实际不可达。文献中未见非 oracle 前端把带噪 SV 恢复到 clean 水平的报告。
- **−5 dB 档：目标 ≤7.739，地板 ≈5.3~5.8。** 余量 ≈2 个点，当前 9.92 → 需再降 ≈2.2 点。最强前端文献结果也难以支撑此幅度。

推论：**天花板不是训练数据量或 loss 形式，而是"冻结 clean 训练的声纹模型 + 纯前端"这一结构本身。** minDCF 的冻结（−2.3%~−2.5%）是佐证：分数分布整体分离度未变，仅 EER 工作点附近小改善。

（对地板论证的反驳空间：若引入后端手段（如 AS-Norm），clean 地板本身可被压低，此时 0 dB 或有一线余地——但这已不属于"前端方案"，恰好支持第 5 节的组合策略。）

## 4. 文献与经验依据【文献，请核验细节】

1. **语音增强做 SV 前端常为负收益或收益不稳**：Garcia-Romero 等《How good is enhancement for speaker verification?》(Odyssey 2020)——oracle 掩蔽/WPE 类增强甚至会降低 SV 性能，伪影损伤说话人线索；Sadiku 等《Investigation of Speech Enhancement and Recognition-Based Front-Ends for Robust Speaker Verification》(Interspeech 2022)——多数 SE 前端无法稳定改善 SV。本项目自有数据（denoised 10.11% > noisy 8.39%）与之一致。
2. **任务感知/联合优化有正增益但幅度中等**：面向 SV 目标（speaker-aware loss、SE+SV 联合训练）的改进工作普遍报告噪声条件下 ~10~25% 相对降幅；超过 30% 的报告通常同时重训/微调了 SV 后端。
3. **多条件鲁棒训练是文献中最可靠的大杠杆**：VoxCeleb 系列配方（MUSAN+RIR 增广）、CN-Celeb 多条件训练等，噪声/混响条件相对 clean 训练模型普遍有 30~60% 相对 EER 降幅，是最稳定的结论之一。
4. **分数归一化/校准提供稳定的小-中增益**：AS-Norm 类方法典型 5~20% 相对降幅（对 minDCF 尤其明显）。
5. InfoNCE 对比学习（van den Oord 2018）、AAM-softmax（Wang 2018）为成熟组件。

## 5. 修订后的方案：三层组合（协议允许性已核对）

课题任务书明确允许的改进方法包括：数据增强、鲁棒训练、去混响、波束形成、目标说话人提取、域适配、多任务学习、后端校准、联合训练；并要求与"同骨干未增强版本、同协议"比较。因此以下全部合规：

- **E1（零训练，先做）：AS-Norm 分数归一化**。对现有 score 文件直接计算，量化后端余量。成本：小时级。
- **E2（主杠杆）：ERes2Net-large 多条件鲁棒微调**。clean + 0 dB + −5 dB 混合（约 1:1:1，同一训练语音动态混噪，仅用 train 噪声），AAM-softmax 延续训练，低 LR、少 epoch，按"噪声 EER 改善 + clean 退化 <1 点"双门限选 checkpoint。**enrollment 与 test 均用微调后模型重新提 embedding**（同模型两侧，消除 clean/noisy 域差）。成本：1~2 天。
- **E3（现有路线升级为辅助项）：跨句+跨设备对比 loss 前端**。anchor=同说话人不同句子、不同 Device 的 clean embedding；query=混噪→增强后 embedding；batch 内其他说话人 anchor 做负例，InfoNCE（温度 ~0.1）。在 E2 的鲁棒模型上评测。成本：~1 天。采样建议改为按说话人（如 3000 人 × 10 句）而非全表均匀。
- **E4：数据放大**。在 E2/E3 有效后，把 30k 扩到 100k~全量 + 更多样噪声类型（MUSAN 全集）。注意：**在 loss/目标正确之前放大数据收益递减（实测：3 倍数据+3 倍 epoch 仅换来 3~5% 相对降幅），目标正确后数据才重新值钱**。

## 6. 概率估计【主观概率】

| 方案 | 0 dB ≥30% | −5 dB ≥30% | 两档同时达标 |
|---|---|---|---|
| A. 仅前端对比 loss（冻结 SV） | <10% | 10~20% | **<10%** |
| B. 仅 E2 鲁棒微调 | 45~60% | 60~75% | 45~60% |
| C. B + AS-Norm | 55~70% | 70~80% | 55~70% |
| D. C + E3 前端 | 60~75% | 75~85% | **60~75%** |

B 的不确定性主要来自：预训练 checkpoint 是否已含噪声增广（不可知，但其 0 dB 相对 clean 退化 +2.6 点提示鲁棒性有限）；30k 子集微调的遗忘风险。E2 的 sanity 实验数小时即可把 B 的概率大幅收窄。

EER≤0.5% 的挑战目标在本协议（3 s、跨设备、ERes2Net）下不可达，实际验收路径为相对降幅条款。

## 7. 风险与缓解

| 风险 | 缓解 |
|---|---|
| E2 微调导致 clean 退化 | 多条件混合含 clean、低 LR、双门限选 checkpoint、早停 |
| 过拟合 train 噪声分布 | 用 MUSAN 全类噪声+随机 SNR 而非仅 freesound；test 噪声隔离已强制 |
| 3 s 短语音敏感 | 训练时随机 3 s 裁剪与测试对齐 |
| 协议合规（阈值冻结、分项报告、不得合并均值） | 沿用现有 sv-ecapa 评测管线；阈值仅从验证集确定 |

## 8. 可证伪的预测（供审核者检验）

1. 仅换 loss（方案 A）训到收敛，0 dB EER 落在 7.2~7.6，无法接近 5.87。
2. E2 完成后，0 dB EER 落在 4.8~6.3，−5 dB 落在 6.0~8.3。
3. AS-Norm 对现有 e10 分数文件可带来 5~15% 相对改善（E1 可立即验证）。
4. 若预测 1 被推翻（A 方案逼近 5.87），则第 3 节地板论证有误，方案应回退到 A。
